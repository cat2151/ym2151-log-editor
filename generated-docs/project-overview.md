# Project Overview

## プロジェクト概要
- YM2151シンセサイザーのイベントログを編集するためのターミナルユーザーインターフェース (TUI) エディタです。
- JSON形式のイベントデータを視覚化し、KeyON表示や時刻表示モード切り替えで直感的な操作を提供します。
- イベントの挿入、削除、タイミング調整、ファイル保存などの基本機能を通じて、YM2151のイベントシーケンス作成を支援します。

## 技術スタック
- フロントエンド: **ratatui 0.29** (ターミナルUIフレームワーク), **crossterm 0.29** (ターミナルバックエンド)
- 音楽・オーディオ: **YM2151** (プロジェクトが対象とするFM音源チップ、直接の技術スタックではないが中心概念)
- 開発ツール: **Cargo** (Rustプロジェクトのビルドおよびパッケージマネージャー), **git** (バージョン管理システム)
- テスト: Rust標準のテストフレームワーク（`src/tests` ディレクトリでのユニットテストや統合テスト）
- ビルドツール: **Cargo** (Rustプロジェクトのビルド、依存関係管理、テスト実行など)
- 言語機能: **Rust 1.70以降** (プログラミング言語), **serde 1.0** (シリアライゼーション/デシリアライゼーションフレームワーク), **serde_json 1.0** (JSON形式のシリアライゼーション/デシリアライゼーション)
- 自動化・CI/CD: (特になし)
- 開発標準: (特になし)
