# Project Overview

## プロジェクト概要
- YM2151シンセサイザーのイベントログをターミナルで編集・可視化するためのRust製エディタです。
- イベントのタイミング調整、データの検査、KeyONイベントの識別など、直感的な操作を提供します。
- JSON形式のイベントデータを扱い、ファイル操作や時間表示モードの切り替えなどの機能を持ちます。

## 技術スタック
- フロントエンド:
    - **ratatui**: ターミナルユーザーインターフェース (TUI) を構築するためのフレームワークです。
    - **crossterm**: ターミナルのバックエンドとして、キー入力や画面描画を制御します。
- データ処理/シリアライゼーション:
    - **serde**: Rustのデータ構造を様々なフォーマット（JSON, YAMLなど）にシリアライズ・デシリアライズするためのフレームワークです。
    - **serde_json**: `serde` を用いてJSON形式のデータを扱うためのクレートです。
- 言語・実行環境:
    - **Rust**: 高性能で安全なシステムプログラミングに適した言語です。
- ビルド・パッケージ管理:
    - **Cargo**: Rustの公式なビルドシステム兼パッケージマネージャです。

## ファイル詳細説明
- **`src/main.rs`**: アプリケーションのエントリーポイント。起動時の設定、TUIの初期化、主要なイベントループの管理を行います。
- **`src/app.rs`**: アプリケーションの全体的な状態を管理し、ユーザー入力に応じたロジック処理（イベント処理、モード切り替えなど）を担当します。
- **`src/models.rs`**: YM2151イベント（`Ym2151Event`）やイベントログ全体（`Ym2151Log`）など、プロジェクトで扱う主要なデータ構造を定義します。JSONデータのパースと生成にも利用されます。
- **`src/ui.rs`**: アプリケーションの状態に基づいて、ターミナル上にユーザーインターフェース（画面要素）を描画するロジックを実装しています。
- **`src/event_editor.rs`**: イベントの挿入、削除、待機時間（wait）の設定など、イベントデータ自体を編集する機能に関するロジックが含まれます。
- **`src/file_io.rs`**: JSON形式のYM2151イベントログファイルを読み込み、保存するための機能を提供します。
- **`src/navigation.rs`**: ターミナルUI上でのイベント間の移動（カーソル移動）や、その他のナビゲーション操作に関するロジックを扱います。
- **`src/preview.rs`**: YM2151イベントログのプレビュー再生機能に関するロジックを実装しています。
- **`src/time_display.rs`**: イベントの時刻表示モード（累積時間 vs 絶対タイムスタンプ）の切り替えと、それぞれの表示形式を管理するロジックです。
- **`src/tests/`**: アプリケーションの各機能やコンポーネントの動作を検証するための単体テストおよび統合テストコードを格納しています。

    - **`src/tests/insert_event_tests.rs`**: イベント挿入機能のテストコードです。
    - **`src/tests/load_from_str_tests.rs`**: 文字列（JSONデータ）からのイベントログ読み込み機能のテストコードです。
    - **`src/tests/loop_tests.rs`**: ループ再生機能のテストコードです。
    - **`src/tests/mod.rs`**: `src/tests` ディレクトリ内のテストモジュールを管理するファイルです。

    - **`src/tests/navigation_tests.rs`**: ナビゲーション機能のテストコードです。

## 関数詳細説明
このプロジェクトはRustのモジュール構造を利用して機能が分割されています。具体的な関数のシグネチャは提供されていませんが、各モジュールには以下のような役割を持つ関数群が存在すると考えられます。

- **`main`モジュール内の関数**: アプリケーションのエントリーポイントとなる`main`関数が含まれ、主要なTUIイベントループの開始と終了を制御します。
- **`app`モジュール内の関数**: アプリケーションの状態を更新するメソッドや、ユーザーからのキー入力を処理してアプリケーションロジックを実行するイベントハンドラー関数群が含まれます。
- **`event_editor`モジュール内の関数**: イベントの追加、削除、選択中のイベントのプロパティ（例: 待機時間）変更など、イベントデータそのものを操作する関数群を提供します。
- **`file_io`モジュール内の関数**: 指定されたパスからJSONファイルを読み込み、パースして`Ym2151Log`構造体を生成する関数（例: `load_file`）や、`Ym2151Log`構造体をJSON形式でファイルに保存する関数（例: `save_file`）が含まれます。
- **`models`モジュール内の関数**: `Ym2151Event`や`Ym2151Log`といったデータ構造の生成、変換、検証などを行うヘルパー関数や関連メソッドが含まれます。
- **`navigation`モジュール内の関数**: 現在の選択イベントを上下に移動させたり、リストの先頭や末尾にジャンプしたりするなど、UI上でのカーソル移動を管理する関数群です。
- **`preview`モジュール内の関数**: YM2151イベントログを再生し、その進行状況を管理するための関数群が含まれます。
- **`time_display`モジュール内の関数**: イベントのタイムスタンプを累積時間表示と絶対時間表示の間で変換したり、表示形式を整形したりする関数群を提供します。
- **`ui`モジュール内の関数**: `ratatui`フレームワークを利用して、アプリケーションの状態（イベントリスト、モード、メッセージなど）をターミナル画面に描画するための関数群（例: `draw_ui`）が含まれます。
