# Project Overview

## プロジェクト概要
-   YM2151シンセサイザーのイベントログを編集・可視化するためのターミナルユーザーインターフェース (TUI) エディタです。
-   JSON形式のイベントデータを読み込み、タイミング調整やイベント検査を支援し、KeyON表示や時刻表示モードを提供します。
-   Rust言語で開発されており、ターミナル上で直感的かつ効率的な操作でイベントログを管理できます。

## 技術スタック
-   フロントエンド:
    -   **ratatui**: ターミナルユーザーインターフェース (TUI) の構築に使用されるRust製のフレームワークです。アプリケーションの画面描画とレイアウトを管理します。
    -   **crossterm**: ターミナル制御のバックエンドライブラリで、キーボード入力の検出やカーソルの移動、色の設定など、ターミナルとの低レベルなインタラクションを提供します。
-   音楽・オーディオ:
    -   **YM2151イベントログ形式**: プロジェクトが扱う主要なデータ形式であり、YM2151シンセサイザーのレジスタ操作イベントをJSONで表現します。
-   開発ツール:
