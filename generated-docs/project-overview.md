# Project Overview

## プロジェクト概要
- YM2151シンセサイザーのイベントログを編集・可視化するターミナルベースのアプリケーションです。
- イベントデータのタイミング調整や検査を支援し、最低限の編集機能を提供します。
- Rust製で、JSON形式のイベントログに対応し、直感的なキーボード操作で利用できます。

## 技術スタック
- フロントエンド: **ratatui** (0.29) - ターミナルユーザーインターフェース (TUI) を構築するためのフレームワークです。**crossterm** (0.29) - ターミナル操作のバックエンドとして、カーソルの移動やキーイベントの処理などを担当します。
- 音楽・オーディオ: **YM2151** - プロジェクトが対象とするFM音源シンセサイザーです。イベントログを扱うため音楽データ処理に関連し、ログのプレビュー再生機能も備えています。
- 開発ツール: **Cargo** - Rust言語の公式パッケージマネージャーおよびビルドツールです。プロジェクトの依存関係の管理、ビルド、テスト、実行を行います。
- テスト: **Rustの標準テスト機能** - 各モジュールの単体テストが `src/tests/` ディレクトリ内に記述されており、コードの品質と信頼性を確保するための基盤となっています。
- ビルドツール: **Cargo** - Rustプロジェクトのビルドプロセス全体を管理します。
- 言語機能: **Rust** - 高速かつ安全なシステムプログラミング言語で、本プロジェクトの基盤となっています。**serde** (1.0) - Rustのデータ構造を様々な形式（JSONなど）にシリアライズ・デシリアライズするための汎用フレームワークです。**serde_json** (1.0) - JSON形式のデータとRustのデータ構造間で変換を行うためのライブラリです。

## ファイル詳細説明
- **`.gitignore`**: Gitによるバージョン管理の対象外とするファイルやディレクトリを指定します。
- **`Cargo.lock`**: プロジェクトのビルド時に使用された全ての依存パッケージの正確なバージョンとチェックサムを記録します。
- **`Cargo.toml`**: Rustプロジェクトのメタデータ（名前、バージョンなど）と、プロジェクトが依存する外部ライブラリ（クレート）を定義します。
- **`IMPLEMENTATION_PLAN.md`**: プロジェクトの詳細な実装計画と、将来的なロードマップが記述されたドキュメントです。
- **`LICENSE`**: プロジェクトの配布および使用に関するライセンス情報が記載されています。
- **`README.ja.md`**: プロジェクトの概要、機能、インストール方法、使用方法などを日本語で説明する主要なドキュメントです。
- **`README.md`**: プロジェクトの概要、機能、インストール方法、使用方法などを英語で説明する主要なドキュメントです。
- **`_config.yml`**: GitHub Pagesなどの静的サイトジェネレータ（Jekyllなど）の設定ファイルで、ドキュメントサイトの構築に使用されます。
- **`generated-docs/`**: ドキュメント生成ツールによって生成されたファイルが格納されるディレクトリです。
- **`googled947dc864c270e07.html`**: Googleサイト検証用のHTMLファイルです。
- **`issue-notes/`**: 開発中の課題や特定の機能に関するメモが記録されたMarkdownファイルが格納されます。
- **`src/`**: プロジェクトのソースコードが格納される主要なディレクトリです。
    - **`src/main.rs`**: アプリケーションのエントリーポイントであり、メインのイベントループと初期化処理を管理します。
    - **`src/app.rs`**: アプリケーション全体の状態を管理し、ユーザー入力に応じたロジックや状態遷移を定義します。
    - **`src/event_editor.rs`**: YM2151イベントの編集（挿入、削除、待機時間設定など）に関するコアロジックを実装します。
    - **`src/file_io.rs`**: YM2151イベントログのJSONファイルへの読み込みと書き込みを処理します。
    - **`src/models.rs`**: YM2151イベント、イベントログなど、アプリケーションで扱うデータの構造（Rustのstruct）を定義します。
    - **`src/navigation.rs`**: ターミナルUI上でのカーソル移動やイベント間のナビゲーションロジックを管理します。
    - **`src/preview.rs`**: 編集中のYM2151イベントログを再生するプレビュー機能に関連するロジックを実装します。
    - **`src/tests/`**: 各ソースコードモジュールの単体テストコードが格納されるディレクトリです。
        - `delete_event_tests.rs`: イベント削除機能のテスト。
        - `insert_event_tests.rs`: イベント挿入機能のテスト。
        - `load_from_str_tests.rs`: 文字列からのデータ読み込み機能のテスト。
        - `loop_tests.rs`: ループ再生機能のテスト。
        - `mod.rs`: テストモジュールをまとめるファイル。
        - `model_tests.rs`: データモデルのテスト。
        - `navigation_tests.rs`: ナビゲーション機能のテスト。
        - `set_wait_time_tests.rs`: 待機時間設定機能のテスト。
    - **`src/time_display.rs`**: イベントの時刻表示モード（累積時間または絶対タイムスタンプ）の切り替えと表示ロジックを管理します。
    - **`src/ui.rs`**: `ratatui` クレートを使用して、ターミナル上にユーザーインターフェースを描画するためのロジックを定義します。
- **`test_data/`**: アプリケーションのテストに使用されるサンプルJSONデータファイルが格納されます。
    - `minimal.json`: 最小限のテスト用JSONデータ。
    - `sample.json`: より複雑なサンプルテスト用JSONデータ。
