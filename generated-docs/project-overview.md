# Project Overview

## プロジェクト概要
- YM2151シンセサイザーのイベントログを編集するためのターミナルベースJSONエディタです。
- イベントデータの可視化と、特にタイミング調整やイベント内容の検査を支援します。
- 最小限の編集機能を提供し、YM2151ログの管理と活用を簡素化することを目指しています。

## 技術スタック
- フロントエンド:
    - **ratatui**: ターミナルユーザーインターフェース (TUI) を構築するためのRust製フレームワークです。これにより、コマンドライン上でリッチなUIが実現されています。
    - **crossterm**: ターミナルの入力、出力、制御を扱うためのクロスプラットフォームライブラリです。`ratatui`のバックエンドとして、ターミナル操作を抽象化します。
- 音楽・オーディオ:
    - **YM2151**: ヤマハのFM音源チップであり、本プロジェクトはYM2151のイベントログ（演奏データ）を扱うことに特化しています。直接的なライブラリはありませんが、プロジェクトの核心となる技術領域です。
- 開発ツール:
    - **cargo**: Rustの公式なビルドシステムおよびパッケージマネージャです。プロジェクトの依存関係の管理、ビルド、テスト、ドキュメント生成などを行います。
    - **git**: ソースコードのバージョン管理システムです。
- テスト:
    - 本プロジェクトではRustの標準テスト機能を用いて、各種ロジックの動作検証が行われています。特定のテストフレームワークは明示されていませんが、`src/tests/`ディレクトリにテストコードが配置されています。
- ビルドツール:
    - **cargo**: Rustコードのコンパイルと実行ファイルを生成します。
- 言語機能:
    - **Rust**: 高い安全性、パフォーマンス、並行性を特徴とするプログラミング言語です。バージョン1.70以降が推奨されています。
- 自動化・CI/CD:

- 開発標準:

## 関数詳細説明
このプロジェクトでは、各ファイルが特定の機能モジュールとして役割を分担しており、それぞれがその機能に関連する関数群を提供しています。具体的な関数名や引数はプロジェクト情報から直接抽出できませんでしたが、各ファイルの役割から以下の通り推測できます。

- **`main.rs`**: アプリケーションの起動と、ターミナルイベント（キー入力など）を処理するメインイベントループを管理する関数群。
- **`app.rs`**: アプリケーションの現在の状態（例：編集モード、選択中のイベント）を保持し、ユーザー入力に応じた状態遷移やロジック実行を制御する関数群。
- **`models.rs`**: YM2151イベント（アドレス、データ、時間）やそれらをまとめたログ構造体を定義し、これらのデータをJSON形式と相互変換する関数群。
- **`ui.rs`**: `ratatui`ライブラリを使用して、イベントリスト、ヘッダー、フッターなど、ターミナル画面に表示されるすべてのUI要素を描画する関数群。
- **`event_editor.rs`**: ユーザーの操作（例：`DELETE`キー、`/`キー、数字キー）に対応し、イベントの削除、新規イベントの挿入、イベント間の待機時間変更を行う関数群。
- **`file_io.rs`**: 指定されたパスからJSONファイルを読み込み、それをYM2151イベントログのデータ構造に変換したり、現在のイベントログデータをJSONファイルとして保存したりする関数群。
- **`navigation.rs`**: 矢印キー入力などに基づいて、イベントリスト内のカーソル位置を上下に移動させたり、特定のイベントを選択したりするロジックを提供する関数群。
- **`preview.rs`**: 現在のイベントログを一時的に再生し、YM2151イベントのシーケンスを確認できるプレビュー機能を提供する関数群。
- **`time_display.rs`**: イベントの時刻表示形式（デルタ時間表示の「累積モード」と絶対時間表示の「タイムスタンプモード」）を切り替えるロジックや、時間データを整形して表示する関数群。
- **`src/tests/`ディレクトリ内の各ファイル**: 各モジュールの特定の機能を独立して検証するためのテスト関数群。例えば、イベントの挿入が正しく行われるか、ナビゲーションが期待通りに動作するかなどを確認します。
