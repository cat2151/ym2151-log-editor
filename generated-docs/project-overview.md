# Project Overview

## プロジェクト概要
- YM2151シンセサイザーのイベントログを編集・可視化するためのターミナルユーザーインターフェース（TUI）アプリケーションです。
- JSON形式のイベントデータを直感的に表示し、タイミング調整やイベント検査を支援することを目的としています。
- イベントの挿入、削除、待機時間設定、ファイル操作などの基本的な編集機能を提供します。

## 技術スタック
- フロントエンド: **ratatui** (ターミナルユーザーインターフェースを構築するためのフレームワーク)、**crossterm** (ターミナル操作の低レベル制御を行うためのバックエンドライブラリ)
- 音楽・オーディオ: **YM2151イベントデータ** (本プロジェクトが扱う中心的なデータ形式で、YM2151シンセサイザーのイベントを記述します)

- 言語機能: **Rust** (所有権システムによるメモリ安全性、パターンマッチング、高度な型システムなどの言語機能を利用しています)

## 関数詳細説明
本プロジェクトはRustで記述されており、以下のような主要な関数が各モジュールに存在すると推測されます。

- **`main.rs`**:
    - `fn main()`: アプリケーションの起動点。ターミナル環境の初期化、`App`構造体の生成、メインイベントループの実行などを担当します。
- **`app.rs`**:
    - `fn new()`: アプリケーションの状態を保持する`App`構造体のインスタンスを初期化します。
    - `fn update()`: アプリケーションの状態を更新する主要なロジック。キー入力やその他のイベントに応じてデータを変更します。
    - `fn handle_event()`: ユーザーからのキー入力やその他のイベントを受け取り、それに応じた処理を呼び出します。
- **`models.rs`**:
    - `struct Ym2151Event::new()`: YM2151イベントの新しいインスタンスを生成します。
    - `struct Ym2151Log::new()`: YM2151イベントログの新しいインスタンスを生成します。
    - `struct Ym2151Log::add_event()`: ログにイベントを追加します。
    - `struct Ym2151Log::remove_event()`: ログからイベントを削除します。
    - `struct Ym2151Log::convert_to_absolute_time()`: 累積時間形式のログを絶対タイムスタンプ形式に変換します。
    - `struct Ym2151Log::convert_to_delta_time()`: 絶対タイムスタンプ形式のログを累積時間形式に変換します。
- **`ui.rs`**:
    - `fn draw_ui()`: `ratatui`クレートを使用して、現在のアプリケーションの状態に基づいてターミナルUIの各要素（イベントリスト、ステータスバーなど）を描画します。
- **`event_editor.rs`**:
    - `fn insert_event()`: 現在のカーソル位置に新しいYM2151イベントを挿入します。
    - `fn delete_event()`: 現在のカーソル位置のYM2151イベントを削除します。
    - `fn set_wait_time()`: 選択されたイベントの待機時間を設定または変更します。
- **`file_io.rs`**:
    - `fn load_log()`: 指定されたパスからJSON形式のYM2151イベントログファイルを読み込み、`Ym2151Log`構造体にパースします。
    - `fn save_log()`: 現在の`Ym2151Log`構造体の内容をJSON形式で指定されたファイルパスに保存します。
- **`navigation.rs`**:
    - `fn move_cursor_up()`: イベントリストのカーソルを上に移動させます。
    - `fn move_cursor_down()`: イベントリストのカーソルを下に移動させます。
- **`preview.rs`**:
    - `fn start_preview()`: YM2151イベントログの再生を開始します。
    - `fn stop_preview()`: YM2151イベントログの再生を停止します。
    - `fn toggle_loop()`: プレビュー再生のループ機能を切り替えます。
- **`time_display.rs`**:
    - `fn toggle_display_mode()`: 時刻表示モード（累積時間と絶対タイムスタンプ）を切り替えます。
    - `fn format_time()`: 現在の表示モードに基づいて時刻を整形して文字列として返します。
